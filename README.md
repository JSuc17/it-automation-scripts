# IT Automation Scripts

PowerShell scripts for IT support, Windows administration, endpoint troubleshooting, and infrastructure automation.

This repository contains practical scripts created for real-world IT operations, including device inventory, BitLocker status checks, WinRM configuration, and endpoint support tasks.

## Purpose

The goal of this repository is to document and share reusable automation scripts that help reduce manual work in IT support and infrastructure environments.

These scripts are focused on:

* Windows endpoint administration
* Technical support troubleshooting
* Infrastructure automation
* Microsoft 365 / Intune support scenarios
* Security and compliance checks
* Remote management preparation

## Scripts

| Script                       | Description                                                                          |
| ---------------------------- | ------------------------------------------------------------------------------------ |
| `get-device-info.ps1`        | Collects basic hardware, operating system, disk, RAM, BIOS, and network information. |
| `bitlocker-status-check.ps1` | Checks BitLocker protection status for local volumes.                                |
| `enable-winrm.ps1`           | Enables and configures WinRM for remote administration scenarios.                    |
